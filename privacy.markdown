셈터는 회원가입이 없고, 계산기에 입력한 값은 브라우저 안에서만 계산되며 서버로 전송되지 않습니다.

**광고와 쿠키.** 이 사이트는 Google AdSense 등 제3자 광고를 게재할 수 있습니다. Google을 포함한 제3자 공급업체는 쿠키를 사용해 사용자의 이전 방문 기록을 바탕으로 광고를 게재합니다. 사용자는 [Google 광고 설정](https://www.google.com/settings/ads)에서 맞춤 광고를 끌 수 있고, [www.aboutads.info](https://www.aboutads.info)에서 제3자 공급업체의 쿠키 사용을 거부할 수 있습니다.

**호스팅.** 사이트는 GitHub Pages에서 호스팅되며, GitHub는 보안 목적으로 방문자 IP 주소를 기록할 수 있습니다.

**Blogger 자동 발행 앱(blogAuto).** 운영자 본인의 Google 계정으로만 쓰는 내부 도구입니다. Google OAuth 로 받은 Blogger 권한(`https://www.googleapis.com/auth/blogger`)은 운영자 본인 블로그에 글을 올리고 예약하는 데만 쓰며, 다른 사용자의 데이터에 접근하거나 Google 사용자 데이터를 판매·공유·저장하지 않습니다. 인증 토큰은 GitHub Actions 비밀 저장소에만 보관합니다. 권한은 [Google 계정 권한 페이지](https://myaccount.google.com/permissions)에서 언제든 해제할 수 있습니다.

문의: GitHub 이슈로 남겨 주세요.

### Privacy Policy (English)

Semter has no user accounts. Calculator inputs stay in your browser. The site may show third-party ads (e.g. Google AdSense) that use cookies; you can opt out at [Google Ad Settings](https://www.google.com/settings/ads). The site is hosted on GitHub Pages.

**Blogger publishing app (blogAuto).** This is an internal tool used only by the site owner with the owner's own Google account. The Blogger scope (`https://www.googleapis.com/auth/blogger`) is used solely to create and schedule posts on the owner's own blog. It does not access other users' data, and Google user data is not sold, shared or stored beyond the OAuth token kept in GitHub Actions secrets. Access can be revoked at any time at [Google Account permissions](https://myaccount.google.com/permissions).

Contact: [GitHub issues](https://github.com/MJ-0218/MJ-0218.github.io/issues)
