# 재검토 — 인도·쇼피 국가별 Blogger 글 (모든 글, 커밋 전 2회 + 기계 검사)

초안을 쓴 뒤 아래 두 번을 **각각 처음부터 끝까지 다시 읽으며** 고친다. 고친 뒤 기계 검사를 돌린다.
하나라도 해결이 안 되면 그 글은 버리고 로그에 이유를 남긴다.

## 1차 — 말투 (그 나라에서 잘 읽히는 블로거처럼)
그 언어로 블로그를 쓰는 사람이 읽었을 때 "번역한 글" 같지 않아야 한다. 아래 표의 말투를 기준으로 읽는다.

| 블로그 | 말투 기준 | 꼭 확인 |
|---|---|---|
| in · English | 따뜻한 인도 영어 정보 블로거. "Hello friends" 정도의 가벼운 인사, 쉬운 말, 짧은 문단 | 정부 용어는 한 번 쉬운 말로 풀었나 / 숫자는 ₹, lakh·crore |
| in · हिंदी | 인기 힌디 정보 블로그 말투. "नमस्ते दोस्तों" 인사, आप 존댓말, 쉬운 구어체 힌디(어려운 산스크리트계 단어 대신 흔한 말) | 영어 고유명사(PM-KISAN, ITR, e-KYC)는 그대로 + 처음 한 번 뜻 풀이 / 데바나가리 맞춤법 |

## 2차 — 독자·사실·정책
1. **사실**: 본문·카드의 숫자·날짜·가격·SPF·용량·성분 %는 전부 claims 에 원문 인용이 있나. 연도·회차가 이번 것인가.
2. **미확정**: "예정·추진 중·예상" 정보는 제목이나 첫 문단에서 밝혔나 (expected / likely / अपेक्षित 등).
3. **체험 날조 없음**: 써 보지 않은 제품의 "써 봤더니", 별점, 전후 비교가 없나.
4. **효능 주장 없음**: 치료·완치·영구 미백·의학적 효과처럼 의약품처럼 들리는 말이 없나. 상세페이지·라벨에 적힌 표현만.
5. **관계 공개**: 쇼핑·제휴 링크가 있으면 첫 추천 바로 앞에 그 언어의 공개 문구가 있나.
6. **링크**: 쇼핑 링크는 `products/<key>.yml`·`stores.yml`·`config affiliates` 에 있는 것만. 다른 판매자 상품은 제휴 ID가 설정된 경우에만.
7. **스토어 비율**: 오늘 이 블로그의 우리 스토어 글이 이미 1편이면 이번 글에는 스토어 상품을 넣지 않는다. 추천 목록 안에서도 절반 이하.
8. **애드센스·구글 정책**: 성인·폭력·위험 행위·도박·의료 오정보·혐오·저작권 침해 이미지 없음. 정치·종교 논쟁, 연예인 사생활 없음.
9. **독자에게 쓸모**: 검색한 사람이 첫 화면에서 답(날짜·금액·방법)을 얻나. 그 나라 사람에게 맞는 정보(현지 가격·날씨·공휴일·세일 날짜)인가.
10. **중복**: 같은 블로그의 최근 글이나 다른 나라 블로그 글을 옮긴 것처럼 보이지 않나.

## 기계 검사 (전부 통과해야 커밋 · Actions 도 발행 전에 같은 검사를 다시 한다)
```bash
python3 automation/scripts/verify_claims.py <글> --fetch     # 열기 실패 시 Actions 수집본으로 대조
python3 automation/scripts/style_check.py <글>
python3 automation/scripts/blog_audit.py <글>                # 링크 허용 목록·효능 표현·미확정 표시·유사 글·하루 편수·스토어 비율
```
매 실행 끝에 인자 없이 `blog_audit.py`를 한 번 더 돌려 최근 14일 글 전체를 다시 본다. 문제가 생긴 글(예: 출처 기사가 바뀜)은 고치거나, 아직 발행 전이면 지운다.
